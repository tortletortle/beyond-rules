# LAWLESS V1.0 动态物理效果

## 本轮目标

在保留 V0.9 规则与关卡系统的前提下，把三种关键法则变化转化为可感知的世界反馈。

## 实现内容

### 1. 重力场
- 在世界视口内加入全局重力方向指示。
- 环境粒子沿全局重力方向运动；进入局部重力格时改为沿该格的局部方向运动。
- 局部重力格绘制方向矢量和流动粒子。
- 改写重力时，玩家位置产生方向变化波纹和粒子爆发。

### 2. 相位系统
- 实体与虚体使用不同的能量核心材质和辉光颜色。
- 虚体状态显示环形相位轨道与旋转碎片。
- 切换相位时产生波纹和粒子爆发；穿越相位墙时增加局部穿越反馈。

### 3. 能量回路
- 压力开关、能量门的外观随开关状态变化。
- 开关与门之间绘制能量导线；门开启后导线高亮并显示移动能量脉冲。
- 能量箱移动时产生金色粒子和冲击波。
- 开关状态改变时，开关与门两端同步产生能量反馈。

## 渲染与可访问性

- 使用 Canvas 连续动画帧渲染环境粒子、能量脉冲和波纹。
- 尊重 `prefers-reduced-motion`，减少动态效果时只绘制静态状态。
- 页面进入后台时暂停动画循环，返回前台后恢复。
- 没有引入外部 CDN、框架或构建依赖。

## 重要边界

这些效果是**视觉表现层**：粒子流用于表达规则方向，能量导线用于表达压力开关与门的逻辑关系，相位碎片用于表达实体/虚体状态。它们不是新增的流体仿真、电磁仿真或真实物理引擎。底层规则状态仍由原有 V0.9 求解器计算。
