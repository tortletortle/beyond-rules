# LAWLESS V0.9 前端视觉预览

## 目标

在不改变 V0.8 规则语义的前提下，降低界面操作负担，并把“改写物理规则”呈现为游戏的核心交互，而不是一组设置表单。

## 信息架构

- **世界档案（左侧）**：关卡选择、谜题进化、自适应训练、学习记录和图例。
- **世界视口（中央）**：关卡目标、Canvas 地图、状态与动作反馈。
- **法则控制台（右侧）**：当前关卡允许的法则、预算进度和世界实验室入口。
- **行动栏（底部）**：方向控制、撤销、重置、提示和下一关。

## 视觉语言

- 深海军蓝底色与低对比边界，避免大量高亮卡片。
- 青色用于玩家能量体与物理反馈；紫色用于相位墙；薄荷绿用于出口；金色用于能量箱、压力开关和能量门。
- Canvas 使用渐变材质、边缘高光和局部辉光，区分不同世界实体。
- 移动端将三栏折叠为纵向布局，并保持无水平滚动。

## 功能边界

本轮只重构界面结构、响应式样式和 Canvas 绘制函数。既有求解器、规则预算、关卡数据、生成谜题、自适应训练、编辑器验证及 JSON 导入导出逻辑保持原样。V0.9 仅表示视觉预览版本，不代表玩法系统已完成新一轮功能验收。

## 后续方向

1. 将单文件原型拆分为渲染层、规则引擎、关卡数据和 UI 状态模块。
2. 为相位墙、重力场、能量门和通关状态增加有节制的动效。
3. 建立规则引擎单元测试与关卡回归测试。
4. 开展真实玩家的任务完成时间、误操作率和规则理解度测试。
