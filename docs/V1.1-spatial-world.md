# LAWLESS V1.1：空间化世界表现

## 设计目标
将 V1.0 的平面网格视觉升级为具有空间纵深的 2.5D 解谜场景，同时保留原有格子坐标、规则状态和求解器。目标不是把 Canvas 伪装成真实 3D 引擎，而是在不引入重型引擎的情况下，让关卡更像悬浮在遗迹深处的实体空间。

## 本轮实现
- 整个棋盘使用统一斜切透视变换，形成空间视角，不再是正对镜头的平面矩形。
- 单格增加石材顶面、暗侧边、倒角、高光和符文刻线。
- 棋盘放置在悬浮石台上，增加底部厚度、侧边阴影和边缘刻线。
- 增加远景环形建筑、断裂桥梁、悬浮遗迹、光束、雾层、垂落结构和环境微粒。
- 关卡主题色随法则变化：逆重力观测站、相位圣殿、熔金回路、静时回廊。
- 相位墙呈现半透明竖直能量屏障；出口使用拱形能量门；能量箱使用多面体晶体造型；玩家增加接触阴影和拖尾。
- 镜头轻微跟随玩家；规则切换和能量箱移动触发短时镜头震动。

## 设计约束
- 当前是 Canvas 2.5D 程序化渲染，不是真正的 3D 模型、PBR 材质或完整物理引擎。
- 背景建筑为程序化绘制；独立概念图仅作为美术方向参考，不是游戏运行截图。
- 关卡仍采用 10×6 逻辑网格，规则引擎、求解器和编辑器不重写。
- 不增加外部 CDN、构建依赖或网络请求。
- 继续尊重 `prefers-reduced-motion`，后台页面暂停动画帧循环。

## 后续建议
1. 真实玩家测试规则可读性、任务理解时间和误操作率。
2. 不同主题增加不同空间结构，而不是只改变主题色。
3. 对低端移动设备做长时间帧率、内存和电量测试。
4. 如需完整 3D，再单独评估 Three.js / WebGPU 与现有逻辑引擎的边界；本轮不提前引入。
