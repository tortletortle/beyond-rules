# 规则之外（LAWLESS）

> 状态：Private 开发仓库 · 原型阶段

## 当前版本状态

- V0.8：既有规则与求解逻辑基线。
- V0.9：前端视觉布局预览，文件位于 `web/lawless_v09.html`。
- V1.0：动态物理效果预览，文件位于 `web/lawless_v10.html`。
- **V1.0 仍是视觉表现层迭代，不代表规则引擎或物理仿真内核升级。**
- 未经验收的功能不得标记为正式完成。

## 运行方式

使用现代浏览器直接打开目标 HTML 文件。当前均为无构建步骤的单文件原型，不依赖外部 CDN；学习记录保存在浏览器本地。

## V1.0 动态效果

- 重力：全局方向指示、全局/局部场粒子流、规则改变波纹。
- 相位：实体/虚体核心材质切换、相位轨道碎片、穿墙反馈。
- 能量回路：压力开关、能量门、开门导线脉冲、箱体移动反馈。
- 支持减少动态效果设置；页面隐藏时暂停动画循环。
